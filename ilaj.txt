# My Herbal — بیماریاں اور علاج
# یہ فائل ویب سائٹ کے بٹن "📋 بیماریاں اور علاج" میں دکھائی جاتی ہے۔
# ہر بیماری کے نام (## والی لائن) کے نیچے لکھیں:
#   مزاج:  اس کے آگے مزاج کا نام
#   علاج:  اس کے آگے اسی مزاج کا علاج / فارمولا (اگلی لائنوں میں بھی لکھ سکتے ہیں)
# ایک بیماری کئی مزاجوں میں ہو تو "مزاج:" اور "علاج:" دوبارہ لکھ دیں، ہر مزاج کا الگ علاج۔
# جو بیماری خالی چھوڑیں گے وہاں ویب سائٹ پر "علاج ابھی درج نہیں" آئے گا۔
# ## والی لائن (بیماری کا نام) نہ بدلیں۔ # سے شروع ہونے والی لائنیں ویب سائٹ پر نظر نہیں آتیں۔
#
# مثال:
#   ## احتلام
#   مزاج: عضلاتی اعصابی
#   علاج: فلاں دوا 1 گرام صبح شام
#   مزاج: غدی اعصابی
#   علاج: فلاں فارمولا
#   پرہیز: ...
